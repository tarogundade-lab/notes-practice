# Progress Note Practice

A single-page exercise for practicing clinical progress notes. Learners read a short counseling scenario, write a note in DAP or SOAP format, and compare it with a sample note.

**What it practices**

- Writing objectively and separating client statements from observations
- Recording the intervention, the client's response, and the plan
- Keeping to clinically relevant facts and leaving out unnecessary personal details

**How to use it:** open `index.html` in any browser. There is nothing to install.

The client and scenario are fictional and were written for training. The tool stores nothing; your note stays in your browser until you close the page.
